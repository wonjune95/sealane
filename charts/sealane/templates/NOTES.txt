Sealane {{ .Chart.AppVersion }} is installed in namespace {{ .Release.Namespace }}.

Try it before exposing it:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "sealane.fullname" . }} 8080:{{ .Values.service.port }}
  open http://localhost:8080

First login: user admin, with the password generated at first start:
  kubectl -n {{ .Release.Namespace }} get secret {{ include "sealane.fullname" . }}-initial-admin -o jsonpath='{.data.password}' | base64 -d; echo
Change it in Settings, then delete that Secret if you like (Sealane only reads it when there is no admin account).
