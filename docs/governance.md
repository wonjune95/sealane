# Governance & adopters

Sealane has a single maintainer, [@wonjune95](https://github.com/wonjune95). Decisions are discussed in public issues and pull requests and made by maintainer consensus. Anyone who contributes steadily for three months (code, reviews, issue triage) can become a maintainer with the approval of every existing maintainer. The full rules are in [`GOVERNANCE.md`](https://github.com/wonjune95/sealane/blob/main/GOVERNANCE.md).

Organizations running Sealane are listed in [`ADOPTERS.md`](https://github.com/wonjune95/sealane/blob/main/ADOPTERS.md). Using it? Add yourself with a pull request.
