# Sealane v0.10.0

## Single sign-on and a documentation site

### Highlights
- **OIDC single sign-on** next to local accounts: authorization code flow with PKCE, groups mapped to `admin` / `editor` / `viewer`, configured with the chart's new `oidc.*` values. Works with Dex, Keycloak, Okta, Entra ID and other OpenID Connect providers; a self-contained Dex demo lives in `examples/dex-demo.yaml`. See [Authentication](https://wonjune95.github.io/sealane/authentication/).
- **Documentation site**: https://wonjune95.github.io/sealane/ (getting started, configuration, authentication, upgrading, compatibility).
- The change history and audit log now record which provider a user signed in with.
- `helm install` succeeds on clusters without Istio: the istiod-reader Role is skipped when the Istio namespace is absent (GitOps renders cannot detect this; set `istioNamespace: ""` there).
- OIDC discovery, token exchange and key fetches are bounded by a 10 s timeout.

### Upgrade notes
- **Everyone signs in again once** after the upgrade: the session cookie format changed to carry the auth provider.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 0.10.0 -n <namespace> --reset-then-reuse-values` — details in [Upgrading](https://wonjune95.github.io/sealane/upgrading/).
- No changes to existing values, environment variables or the accounts ConfigMap format.

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 0.10.0 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v0.10.0/install.yaml
```
Image `ghcr.io/wonjune95/sealane:0.10.0` (linux/amd64, linux/arm64) and the chart are signed with cosign (keyless); the SBOM is attached below.
