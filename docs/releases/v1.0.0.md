# Sealane v1.0.0

## Policy and ecosystem

### Highlights
- **1.x stability promise**: Helm values, environment variables, the accounts ConfigMap and clusters Secret formats and the `install.yaml` object names do not change incompatibly within 1.x; a session-cookie change costs at most one re-login. See [Versioning and support](https://wonjune95.github.io/sealane/versioning/).
- **Governance and adopters**: `GOVERNANCE.md` describes how decisions are made and how to become a maintainer; `ADOPTERS.md` lists organizations running Sealane.
- **Wider CI**: the e2e job runs on Istio 1.30.5 and 1.31.1, and a new upgrade job installs 0.8.0, seeds accounts, upgrades to the current chart and checks that logins and roles survive.
- **Clean rollouts**: the pod waits `SHUTDOWN_DELAY` (default 5s) before closing the listener, so in-flight requests and endpoint updates finish. With two replicas, requests keep flowing through a rolling update (the old pod keeps serving for 5 s after it leaves the Service).
- **Secure cookies behind https**: session and sign-in cookies are marked `Secure` when `OIDC_REDIRECT_URL` is https.
- **OIDC sign-in state**: a forged or stale callback no longer clears the state cookie of a login in progress.
- **Release notes in the repository**: they live in `docs/releases/` and are shown on the documentation site and in the GitHub Release.
- **Ecosystem kit** (`hack/`, `docs/announcement*.md`, `artifacthub-repo.yml`): Artifact Hub metadata, announcement drafts, an istio.io integrations page draft and a CNCF Landscape logo and entry. These are submitted from the maintainer's accounts; nothing is published by CI.

### Upgrade notes
- No breaking changes; existing sessions stay valid.
- Pod termination takes 5 seconds longer because of `SHUTDOWN_DELAY`; set `SHUTDOWN_DELAY=0s` to disable (no Helm value in 1.0: `kubectl -n <ns> set env deploy/sealane SHUTDOWN_DELAY=0s`).
- If `OIDC_REDIRECT_URL` is https but Sealane is reached over plain http (TLS terminated elsewhere), logins would fail now that cookies are `Secure`. Keep the redirect URL on the scheme users actually use.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.0.0 -n <namespace> --reset-then-reuse-values` — details in [Upgrading](https://wonjune95.github.io/sealane/upgrading/).

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.0.0 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v1.0.0/install.yaml
```
Image `ghcr.io/wonjune95/sealane:1.0.0` (linux/amd64, linux/arm64) and the chart are signed with cosign (keyless); the SBOM is attached below.
