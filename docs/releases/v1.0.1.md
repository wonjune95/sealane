# Sealane v1.0.1

## Chart pass-through values

### Highlights
- **`extraEnv`, `extraVolumes`, `extraVolumeMounts`**: new Helm values copied into the pod as-is. They cover the gaps 1.0.0 left to `kubectl set env`: `SHUTDOWN_DELAY`, a proxy, and above all a **private CA for the OIDC issuer** (`SSL_CERT_FILE` plus a ConfigMap mount, see [Private CA](https://wonjune95.github.io/sealane/authentication/#private-ca)). Without it, an IdP with an internal certificate fails at startup with `x509: certificate signed by unknown authority`.

The image is otherwise 1.0.0 plus Dependabot's minor and patch frontend dependency updates (PR #4); no functional change.

### Upgrade notes
- No breaking changes; existing sessions stay valid. The defaults render the same pod as 1.0.0.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.0.1 -n <namespace> --reset-then-reuse-values` — details in [Upgrading](https://wonjune95.github.io/sealane/upgrading/).

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.0.1 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v1.0.1/install.yaml
```
Image `ghcr.io/wonjune95/sealane:1.0.1` (linux/amd64, linux/arm64) and the chart are signed with cosign (keyless); the SBOM is attached below.
