# Sealane v1.1.0

## Mesh analysis and service view

### Highlights
- **Mesh analysis** (`/analysis`): cross-resource checks that explain why traffic would not flow — destinations and backends that do not exist or have no ready endpoints, undefined subsets, missing gateways, hosts claimed twice on one gateway, routes and Gateways the controller did not accept, and subsets or gateway selectors that match no pod. See [Mesh analysis](https://wonjune95.github.io/sealane/features/#mesh-analysis).
- **Service view** (`/services`): everything that applies to one Service — VirtualServices, DestinationRules, HTTPRoutes, their gateways, security policies by scope, and the findings that concern it.
- **Status in lists**: resource lists show a pill from Gateway API conditions and Istio validation messages (the latter need istiod analysis, `PILOT_ENABLE_ANALYSIS=true`).
- **Login throttle**: five failed local sign-ins inside ten minutes, counted per user name and per client address as reported by your proxy (the last `X-Forwarded-For` entry, else the connection address), block that key for a minute (HTTP 429). The per-user limit holds even if a client forges the header. Without a proxy header the connection address is shared by everyone behind a port-forward or a LoadBalancer without proxy protocol, so five failures by anyone block that address for a minute; and one wrong password per minute keeps a named account blocked, because the block restarts while the five failures stay inside the window.
- **Groups in the login log**: the `login` line for SSO sign-ins carries the `groups` the IdP sent, to debug role mapping.
- **`oidc.hideLocalLogin`**: show only the SSO button on the login page (`/?local=1` brings the form back; the API still accepts local logins).

### Upgrade notes
- No breaking changes; existing sessions stay valid.
- The ClusterRole gains `pods` get/list for the analysis pod checks (only labels are read); without it those checks are skipped. The request tester now adds only `pods/exec`.
- Repeated failed local sign-ins now get HTTP 429 for a minute.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.1.0 -n <namespace> --reset-then-reuse-values` — details in [Upgrading](https://wonjune95.github.io/sealane/upgrading/).
