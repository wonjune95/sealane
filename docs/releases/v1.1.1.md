# Sealane v1.1.1

## Groups from userinfo

### Highlights
- **Userinfo fallback for OIDC groups**: when the ID token has no groups claim at all, Sealane now reads the groups from the provider's userinfo endpoint, like Argo CD's `enableUserInfoGroups`. Gitea reuses the scopes a user approved the first time they authorized an application, so users who authorized a shared application through another client got ID tokens without `groups` and fell through to `defaultRole`; Gitea's userinfo always returns them. Other providers that put groups only in userinfo benefit the same way. An empty groups list in the token still means "no groups", and a failed userinfo call is logged (`oidc userinfo`) and costs only the groups, never the sign-in. See [Groups to role](https://wonjune95.github.io/sealane/authentication/#how-it-works).
