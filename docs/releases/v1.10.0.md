# Sealane v1.10.0

## Seed local accounts from Helm values

### Highlights
- **`accounts` chart value.** Local accounts can now be declared in values (`user: "role:bcryptHash"`) for GitOps installs where nobody edits the ConfigMap by hand. When set, the chart renders the accounts ConfigMap and owns it: every `helm upgrade` rewrites it to the list in values (so password changes made in the UI are reverted) and `helm uninstall` keeps it. Left empty (the default), nothing changes: Sealane creates the ConfigMap with `admin`/`admin` at first start and the settings page edits it, untouched by Helm. The schema rejects values whose role is not `admin`, `editor` or `viewer`.

### Upgrade notes
- No breaking changes; the default render is identical to 1.9.0. Do not set `accounts` while a ConfigMap of that name already exists outside Helm — delete it first, Helm will not adopt it.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.10.0 -n <namespace> --reset-then-reuse-values`

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.10.0 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v1.10.0/install.yaml
```
