# Sealane v1.11.0

## The ConfigMaps are in the manifest now

### Highlights
- **`sealane-cm` settings ConfigMap.** Single sign-on is configured the way Argo CD's `argocd-cm` works: the chart and `install.yaml` ship an empty `sealane-cm` whose comments list every `OIDC_*` key (issuer, client ID, redirect URL, claims, group-to-role mapping, default role, button label, `LOCAL_LOGIN`). The pod reads it through `envFrom`, so without Helm you edit the ConfigMap, put the client secret in `sealane-secret` (key `OIDC_CLIENT_SECRET`) and restart the pod; `kubectl get cm sealane-cm` shows what is configured. With Helm the `oidc.*` values render into the same ConfigMap, and `clientSecretRef` keeps working.
- **Accounts ConfigMap in the manifest.** `sealane-accounts` is rendered by the chart and `install.yaml` (empty, with the format and the kubectl commands in comments, `helm.sh/resource-policy: keep`). Sealane still adds `admin`/`admin` at first start and the UI edits it; Helm manages only the keys listed under the `accounts` value and leaves the rest alone, and `helm uninstall` keeps the ConfigMap.

### Upgrade notes
- **One-time step for Helm installs from 1.10 or earlier:** Helm refuses to adopt the accounts ConfigMap it did not create. Before upgrading, label it (see [Upgrading](https://github.com/wonjune95/sealane/blob/main/docs/upgrading.md#from-110x-to-111x)):
  ```sh
  NS=<namespace>; CM=sealane-accounts      # or istio-dashboard-accounts
  kubectl -n $NS annotate cm $CM meta.helm.sh/release-name=sealane meta.helm.sh/release-namespace=$NS
  kubectl -n $NS label cm $CM app.kubernetes.io/managed-by=Helm
  ```
  Without it the upgrade stops with `invalid ownership metadata` and changes nothing. `install.yaml` users just apply the new file.
- `oidc.clientSecretRef.name` is no longer required by the chart: leave it empty to read the secret from `<release>-secret`. Values, accounts and sessions are otherwise unchanged.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.11.0 -n <namespace> --reset-then-reuse-values`

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.11.0 -n sealane --create-namespace
# or

```
