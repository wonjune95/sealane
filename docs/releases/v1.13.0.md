# Sealane v1.13.0

## The traffic flow map looks like a service graph now

### Highlights
- **Kiali-style graph.** The traffic flow page draws one SVG graph instead of four columns of cards: a dashed box per namespace, small shaped nodes (rounded square = gateway, diamond = route, circle = service, dashed circle = external host) with the kind icon inside and the name plus host or endpoint count underneath, arrowed edges from left to right, a red badge on anything that needs attention, and a legend under the graph. Selecting a node highlights its path and dims the rest; drag, zoom, fit, reset, search, namespace and problem filters, keyboard selection and the details panel work as before. The data is still routing configuration only, so there is no metrics dependency.

### Upgrade notes
- No breaking changes, no new values, no manual step. Upgrading from 1.10 or earlier with Helm still needs the accounts ConfigMap adoption described in the [1.11.0 notes](v1.11.0.md).
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.13.0 -n <namespace> --reset-then-reuse-values`

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.13.0 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v1.13.0/install.yaml
```
Image `ghcr.io/wonjune95/sealane:1.13.0` (linux/amd64, linux/arm64) and the chart are signed with cosign (keyless); the SBOM is attached below.
