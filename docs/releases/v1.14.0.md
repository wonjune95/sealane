# Sealane v1.14.0

## See which tool owns a resource before you edit it

### Highlights
- **Owner badge in resource lists.** Rows for resources that Argo CD, Flux or Helm manage show the tool name next to the resource name; hovering it explains what happens to edits made here. The list search matches the tool name, so typing "argo cd" lists every Argo CD-managed resource of that kind.
- **Warning in the editor.** Opening a managed resource shows a warning above the editor: Argo CD and Flux revert edits made here on their next sync (or report the resource out of sync), and the next `helm upgrade` overwrites them. Editing is not blocked, so an emergency fix still works; change the source in Git or the chart values afterwards.
- **What is detected.** Argo CD's `argocd.argoproj.io/tracking-id` annotation (annotation tracking, the default since Argo CD 3.0) or an `argocd.argoproj.io/instance` label, Flux's `kustomize.toolkit.fluxcd.io/name` and `helm.toolkit.fluxcd.io/name` labels, and the `meta.helm.sh/release-name` annotation written by `helm install` and `helm upgrade`. Argo CD's older label tracking on `app.kubernetes.io/instance` is not detected because Helm charts set the same label. The list and detail API responses carry the owner as `managedBy: {tool, name}`.

### Upgrade notes
- No breaking changes, no new values, no manual step. Upgrading from 1.10 or earlier with Helm still needs the accounts ConfigMap adoption described in the [1.11.0 notes](v1.11.0.md).
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.14.0 -n <namespace> --reset-then-reuse-values`

### Install

helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.14.0 -n sealane --create-namespace
