# Sealane v1.14.1

## Smoother Korean owner warning

### Highlights
- **Korean wording.** The Korean owner badge tooltip and editor warning no longer put the `이(가)` particle after the tool name ("Argo CD에서 관리하는 리소스입니다"). English text and behaviour are unchanged.

### Upgrade notes
- No breaking changes, no new values, no manual step.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.14.1 -n <namespace> --reset-then-reuse-values`

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.14.1 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v1.14.1/install.yaml
```
Image `ghcr.io/wonjune95/sealane:1.14.1` (linux/amd64, linux/arm64) and the chart are signed with cosign (keyless); the SBOM is attached below.
