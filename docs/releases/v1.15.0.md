# Sealane v1.15.0

## Private CA without patching, and docs for air-gapped and Korean-speaking teams

### Highlights
- **Private CA through a ConfigMap.** `install.yaml` and the chart now create an empty `sealane-tls-certs` ConfigMap (`<release>-tls-certs` with Helm), like Argo CD's `argocd-tls-certs-cm`. Put a PEM certificate under any key and restart; Sealane trusts it next to the system roots (`SSL_CERT_DIR=/etc/ssl/certs:/etc/sealane/tls-certs`). An IdP signed by an internal CA no longer needs a Deployment patch or `extraVolumes`. With Helm, the new `tlsCerts` value renders certificates into it. See [Private CA](../authentication.md#private-ca).
- **PodDisruptionBudget.** A PDB with `maxUnavailable: 1` keeps one pod serving during node drains when you run two or more replicas; with one replica a drain still proceeds. `podDisruptionBudget.enabled=false` turns it off.
- **Air-gapped install guide.** A new page covers collecting and verifying the image, pushing it with its digest pinned in `install.yaml`, and the settings `install.yaml` does not carry, with which of them survive the next `kubectl apply`. See [Air-gapped install](../air-gapped.md).
- **Korean docs.** Getting started, air-gapped install, authentication, operations and FAQ are available in Korean under **Korean** in the docs navigation.
- **Docs work offline.** The architecture diagram is plain text now, so a docs build carried into a closed network renders without fetching a script.

### Upgrade notes
- No breaking changes and no manual step. The chart adds the `tls-certs` ConfigMap, a volume and the `SSL_CERT_DIR` variable to the Deployment, and the PodDisruptionBudget.
- If you added a private CA with `SSL_CERT_FILE` and `extraVolumes` (or a Deployment patch on an `install.yaml` install), it keeps working: Go reads that file in addition to the directories. Moving the certificate into `sealane-tls-certs` lets you drop the patch.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.15.0 -n <namespace> --reset-then-reuse-values`

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.15.0 -n sealane --create-namespace

```
