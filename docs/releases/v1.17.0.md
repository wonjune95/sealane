# Sealane v1.17.0

## A traffic graph that looks like Kiali's, and adding clusters without the paperwork

### Highlights
- **Kiali's graph look.** The traffic flow graph now uses the shape vocabulary and colours of Kiali 2's graph (PatternFly topology): 40 px nodes (circle = request source, square = gateway, hexagon = route, diamond = Service, trapezoid = external host or ServiceEntry) without icons inside, the name in a label pill underneath, a green outline for Services with ready endpoints and a red outline plus a `!` mark for problems, and a purple `VS` or `HR` mark for the route kind. Namespaces are grey boxes with a dark `NS` label on the bottom edge, and boxes whose stages do not overlap sit side by side, so most edges run straight across. Edges are 3 px arrowed lines without animation; a selected node is filled with the accent colour. Zoom, fit, reset and a legend toggle live in a control bar in the graph's lower left. The data is still routing configuration only.
- **Add a cluster from your own kubeconfig.** On the settings page, paste or load a kubeconfig (a whole `~/.kube/config` works), pick the context, and the name fills in. By default Sealane uses those credentials once to create a limited `sealane-remote` ServiceAccount on that cluster, with the rights the chart gives the local one (and the impersonation RBAC when that mode is on), and stores only that account's token, like `argocd cluster add`. Only the chosen context is ever stored. Kubeconfigs that need a credential plugin (aws, gcloud, kubelogin) are refused with a message saying so. See [Multi-cluster](../multi-cluster.md#registering-a-cluster).

### Upgrade notes
- No breaking changes, no new values, no manual step.
- Clusters registered before keep their stored kubeconfig. To switch one to a dedicated account, register it again with the same name.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.17.0 -n <namespace> --reset-then-reuse-values`

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.17.0 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v1.17.0/install.yaml
```
Image `ghcr.io/wonjune95/sealane:1.17.0` (linux/amd64, linux/arm64) and the chart are signed with cosign (keyless); the SBOM and `impersonation.yaml` are attached below.
