# Sealane v1.17.1

## The traffic graph keeps a shared gateway in the middle

### Highlights
- **Gateway in the middle.** On clusters where one gateway serves routes in many namespaces, 1.17.0 put the gateway's box at the top of a long stack of namespace boxes, so every edge ran down from one corner. A box that holds only gateways now sits level with the middle of the routes it feeds, and the request source sits beside it, so the graph fans out the way Kiali's does.
- **Box labels stay readable.** Namespace labels are drawn above the edges, so edges fanning out of a gateway no longer cover them.

### Upgrade notes
- No breaking changes, no new values, no manual step.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.17.1 -n <namespace> --reset-then-reuse-values`

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.17.1 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v1.17.1/install.yaml
```
Image `ghcr.io/wonjune95/sealane:1.17.1` (linux/amd64, linux/arm64) and the chart are signed with cosign (keyless); the SBOM and `impersonation.yaml` are attached below.
