# Sealane v1.18.0

## A livelier traffic graph

### Highlights
- **Traffic dots.** Small dots slide along every edge toward its target, like Kiali's traffic animation, so the direction of each configured path reads at a glance. A selected path's dots take the accent colour, broken paths carry none, and the dots are hidden for users whose system asks for reduced motion. **Animation** in the graph's control bar switches them off.
- **More room for the graph.** The four count cards above the graph are gone: the route count is on the Ingress and Egress tabs and the problem count on **Problem paths**, so the graph starts higher on the page.
- **Boxes move with their nodes.** A namespace box is drawn around its nodes where they are, so dragging a node out stretches the box with it. Dragging the box itself moves every node in it, as with Kiali's groups. **Reset layout** puts everything back.

### Upgrade notes
- No breaking changes, no new values, no manual step.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.18.0 -n <namespace> --reset-then-reuse-values`

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.18.0 -n sealane --create-namespace
# or
```
