# Sealane v1.18.1

## Edges stay clear of labels

### Highlights
- **Curved edges.** Edges leave and enter nodes horizontally again. On a cluster where one gateway feeds routes in a dozen namespaces, straight edges ran almost vertically across other routes' labels; now the vertical part runs in the gap between the boxes and each edge turns into its route.
- **Long namespace names fit their label.** The label pill on a namespace box is sized for its semibold text, so a name such as `commandcenter` no longer runs into the `NS` badge.

### Upgrade notes
- No breaking changes, no new values, no manual step.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.18.1 -n <namespace> --reset-then-reuse-values`

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.18.1 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v1.18.1/install.yaml
```
