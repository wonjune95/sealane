# Sealane v1.18.2

## The 1.18.1 changes, published

### Highlights
- **Same changes as 1.18.1.** Curved edges that keep clear of labels when one gateway feeds many routes, and namespace labels sized for long names. 1.18.1 was tagged but never published: signing timed out at Sigstore's transparency log (Rekor accepted the entry after cosign's 30-second timeout, and cosign's retry was rejected as a duplicate).
- **Sturdier release signing.** The release workflow now retries signing up to three times, and signs the chart by its pushed digest instead of its tag.

### Upgrade notes
- No breaking changes, no new values, no manual step. Upgrade from 1.18.0 directly; skip 1.18.1.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.18.2 -n <namespace> --reset-then-reuse-values`

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.18.2 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v1.18.2/install.yaml
```
Image `ghcr.io/wonjune95/sealane:1.18.2` (linux/amd64, linux/arm64) and the chart are signed with cosign (keyless); the SBOM and `impersonation.yaml` are attached below.
