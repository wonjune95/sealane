# Sealane v1.18.3

## Drag nodes anywhere

### Highlights
- **No invisible fence.** Nodes and namespace boxes used to stop at the edge of the canvas the layout was drawn on, even with empty space to the right of it. The canvas now spans the graph's full width and grows as you drag a node or box right or down, with the view scrolling to follow. Only the top and left edge stop a drag, so nothing slides out of reach. **Fit to screen** takes the moved nodes into account.

### Upgrade notes
- No breaking changes, no new values, no manual step.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.18.3 -n <namespace> --reset-then-reuse-values`

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.18.3 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v1.18.3/install.yaml
```
Image `ghcr.io/wonjune95/sealane:1.18.3` (linux/amd64, linux/arm64) and the chart are signed with cosign (keyless); the SBOM and `impersonation.yaml` are attached below.
