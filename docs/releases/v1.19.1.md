# Sealane v1.19.1

## The 1.19.0 changes, published

### Highlights
- **Everything in [1.19.0](v1.19.0.md).** The security release for open distribution: a generated initial admin password, sessions that end when the account changes, cross-site request protection and Secure cookies, kubeconfigs that cannot reach Sealane's own files, removable remote accounts, a read-only ServiceAccount in impersonation mode, change-history objects in a Secret, narrower RBAC with no Role in `istio-system`, signed checksums and license notices with every release. 1.19.0 was tagged but never published.
- **go-jose 4.1.6.** The release scan that 1.19.0 introduced stopped it on go-jose 4.1.4 (pulled in by the single sign-on library), which has a denial of service fixed in 4.1.6 (CVE-2026-116587). Nothing was pushed for 1.19.0.

### Upgrade notes
- Upgrade from 1.18.x (or any 1.x) directly; skip 1.19.0. Everyone signs in again once, and an `admin` still on `admin` / `admin` must change it first.
- Read the [1.19.0 upgrade notes](v1.19.0.md#upgrade-notes) and [From 1.11–1.18 to 1.19](../upgrading.md#from-111118-to-119).
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.19.1 -n <namespace> --reset-then-reuse-values`

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.19.1 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v1.19.1/install.yaml
# first sign-in: user admin, password from
kubectl -n sealane get secret sealane-initial-admin -o jsonpath='{.data.password}' | base64 -d; echo
```
Image `ghcr.io/wonjune95/sealane:1.19.1` (linux/amd64, linux/arm64) and the chart are signed with cosign (keyless). `SHA256SUMS` covers every asset below and is signed too (`SHA256SUMS.sigstore.json`); see [Air-gapped install](../air-gapped.md) for verifying it.
