# Sealane v1.19.3

## Small follow-ups to 1.19.2

### Highlights
- **A failing API discovery no longer slows every request.** When rediscovering the installed kinds fails, the last list is kept for another minute instead of being retried on each request.
- **Forms follow CRD upgrades.** The schema behind a form is cached per served version, so a CRD upgrade that changes the version gets its new schema without a restart.
- **Password changes check first.** The current password is verified before the new one is hashed, so wrong attempts cost less.
- **Remote accounts.** A registration that created only the service account (the namespace was left over) is also removed again when the kubeconfig cannot be stored.
- **Release workflow.** The gate counts only `main` push runs (and CodeQL's own runs) of the tagged commit, and pre-releases never move `latest`.
- **Sign-in page.** An SSO error from the identity provider stays visible even when the sign-in screen is shown twice while the app checks the session. The danger confirmation in the change preview has an accessible name.

### Upgrade notes
- No breaking changes, no new values, no manual step beyond those of [1.19.2](v1.19.2.md).
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.19.3 -n <namespace> --reset-then-reuse-values`

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.19.3 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v1.19.3/install.yaml
# first sign-in: user admin, password from
kubectl -n sealane get secret sealane-initial-admin -o jsonpath='{.data.password}' | base64 -d; echo
```
Image `ghcr.io/wonjune95/sealane:1.19.3` (linux/amd64, linux/arm64) and the chart are signed with cosign (keyless). `SHA256SUMS` covers every asset below and is signed too (`SHA256SUMS.sigstore.json`); see [Air-gapped install](../air-gapped.md) for verifying it.
