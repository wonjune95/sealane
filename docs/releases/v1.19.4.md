# Sealane v1.19.4

## The cluster menu shows a new cluster at once

### Highlights
- **Header cluster menu updates right away.** After registering or deleting a cluster in Settings, the cluster menu at the top right still showed the old list until the page was reloaded, so a cluster that had just been added looked missing. Both lists now refresh together.

### Upgrade notes
- No breaking changes, no new values, no manual step.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.19.4 -n <namespace> --reset-then-reuse-values`

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.19.4 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v1.19.4/install.yaml
# first sign-in: user admin, password from
kubectl -n sealane get secret sealane-initial-admin -o jsonpath='{.data.password}' | base64 -d; echo
```
Image `ghcr.io/wonjune95/sealane:1.19.4` (linux/amd64, linux/arm64) and the chart are signed with cosign (keyless). `SHA256SUMS` covers every asset below and is signed too (`SHA256SUMS.sigstore.json`); see [Air-gapped install](../air-gapped.md) for verifying it.
