# Sealane v1.2.0

## Navigation and home

### Highlights
- **More room for resource kinds**: the "current workspace" card is gone from the sidebar and the main links are tighter, so the resource-kind list below them gets the height back. At 1280×820 the Gateway API group and the first Traffic kinds are visible without scrolling.
- **Cluster switcher**: the header picker now reads as one: a "Cluster" label, a connection dot for the selected cluster (green while its API answers), and a "Manage clusters…" entry that opens Settings, where each cluster's status is checked. It is still a native `<select>`, so keyboards and screen readers work as before. On phones the picker sits at the top of the navigation drawer.
- **Home cards**: two new shortcuts next to traffic flow and the request console. Mesh analysis shows the current error and warning counts; Services opens the per-Service view.
- **Fixes**: the severity pill in mesh analysis no longer wraps into one character per line in Korean; the search box in the analysis, services, resource list and all-resources toolbars keeps its width at 1024 px and takes its own row on phones, and the Namespace label is no longer clipped. The breadcrumb and browser tab title now say Mesh analysis and Services instead of Resource.

### Upgrade notes
- No breaking changes; values, environment variables and existing sessions keep working.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.2.0 -n <namespace> --reset-then-reuse-values` — details in [Upgrading](https://wonjune95.github.io/sealane/upgrading/).

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.2.0 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v1.2.0/install.yaml
```
Image `ghcr.io/wonjune95/sealane:1.2.0` (linux/amd64, linux/arm64) and the chart are signed with cosign (keyless); the SBOM is attached below.
