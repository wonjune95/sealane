# Sealane v1.20.0

## A new look

### Highlights
- **Operations-console layout.** A dark navy sidebar holds the cluster picker, the main screens, the resource kinds and your account; the header keeps the breadcrumb, language and theme. Pages use a light grey canvas with white panels, smaller radii and the Inter typeface, bundled with the app so air-gapped installs need nothing from the internet.
- **New home page.** Counts of healthy resources and of those with warnings or errors (from the mesh analysis and each resource's status conditions), a table of every resource with problems first and a filter by category, the latest analysis findings and recent changes, side by side. The sidebar shows the number of analysis errors next to **Mesh analysis**.
- **Kind badges.** Resources show a short coloured badge (VS, DR, HR, AP …), blue for Istio traffic, teal for Gateway API, brown for security and grey for telemetry.
- **Icons and favicon.** Icons come from Lucide, and Sealane has a new mark: a route splitting in two.
- The docs site uses the same navy and teal.

### Fixes
- Updated `fast-uri` (used by the form validator) to releases without its published advisories.

### Upgrade notes
- No breaking changes, no new values, no manual step. Browsers may show the old favicon until their cache expires.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.20.0 -n <namespace> --reset-then-reuse-values`

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.20.0 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v1.20.0/install.yaml
# first sign-in: user admin, password from
kubectl -n sealane get secret sealane-initial-admin -o jsonpath='{.data.password}' | base64 -d; echo
```
Image `ghcr.io/wonjune95/sealane:1.20.0` (linux/amd64, linux/arm64) and the chart are signed with cosign (keyless). `SHA256SUMS` covers every asset below and is signed too (`SHA256SUMS.sigstore.json`); see [Air-gapped install](../air-gapped.md) for verifying it.
