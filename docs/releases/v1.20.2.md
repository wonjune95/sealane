# Sealane v1.20.2

## Fixes to the new look

### Highlights
- **New mark: two waves.** The favicon and the logo in the sidebar and on the sign-in page are now two white waves on teal. Their URLs carry a version, so browsers fetch the new icon instead of keeping the cached one (the server sends no cache validators for these files).
- **Pages no longer scroll past the layout.** On a short window the whole page, sidebar and header included, could scroll up out of view: hidden screen-reader text inside the kind badges was positioned against the window instead of the content area. It now stays inside the scrolling content.
- **Recent changes rows stay readable.** Each change shows the resource on its own line, then what happened, who did it and how long ago ("5 min. ago", full time on hover). Long names and older dates no longer squeeze the row or push **Restore** over the text.

### Upgrade notes
- No breaking changes, no new values, no manual step.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.20.2 -n <namespace> --reset-then-reuse-values`

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.20.2 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v1.20.2/install.yaml
# first sign-in: user admin, password from
kubectl -n sealane get secret sealane-initial-admin -o jsonpath='{.data.password}' | base64 -d; echo
```
Image `ghcr.io/wonjune95/sealane:1.20.2` (linux/amd64, linux/arm64) and the chart are signed with cosign (keyless). `SHA256SUMS` covers every asset below and is signed too (`SHA256SUMS.sigstore.json`); see [Air-gapped install](../air-gapped.md) for verifying it.
