# Sealane v1.3.0

## Curated forms, list summaries and sorting

### Highlights
- **VirtualService form**: hosts, gateways and HTTP rules (URI and header matches, destinations with subset, port and weight, timeout, retries, URI rewrite) instead of the generated schema form. Subset suggestions follow each destination's host.
- **DestinationRule form**: host, subsets with labels, TLS mode and simple load balancer.
- Both keep `exportTo`; any other field (fault injection, mirroring, connection pools, per-subset policies, …) locks the Form tab and the object is edited in YAML, as with HTTPRoute.
- **List summaries for every kind**: Gateway, Sidecar, EnvoyFilter, PeerAuthentication, Telemetry, the Gateway API routes and the rest now show a one-line summary instead of a blank cell.
- **Sorting and paging**: resource lists sort by Namespace, Name, Summary (status first) and Age; Services and all-resources lists sort too. Long lists show 50 rows at a time with "Show more".
- **Home**: the Mesh analysis card turns amber with a warning icon while there are findings.
- **Fixes**: the HTTPRoute form's Hostnames "+ Add" row no longer disappears before it is filled; finding codes in mesh analysis sit on their own line on phones.
- **CI**: the fixture-based browser tests (`npm run test:ui`) run on every push to `main` and on pull requests.

### Upgrade notes
- No breaking changes; values, environment variables and existing sessions keep working.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.3.0 -n <namespace> --reset-then-reuse-values` — details in [Upgrading](https://wonjune95.github.io/sealane/upgrading/).

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.3.0 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v1.3.0/install.yaml
```
