# Sealane v1.3.2

## Settings page layout

### Highlights
- **Settings page**: the four panels now sit in two equal columns — your account and password change on the left, account and cluster management on the right — so the boxes line up and no empty space opens under the short "My account" panel. Non-admin users see only the left column.

No chart or API change; the image carries only this frontend fix.

### Upgrade notes
- No breaking changes; existing sessions stay valid.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.3.2 -n <namespace> --reset-then-reuse-values`

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.3.2 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v1.3.2/install.yaml
```
Image `ghcr.io/wonjune95/sealane:1.3.2` (linux/amd64, linux/arm64) and the chart are signed with cosign (keyless); the SBOM is attached below.
