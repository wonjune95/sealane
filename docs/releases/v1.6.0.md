# Sealane v1.6.0

## Hints on every finding, a Service picker in the request console, create-from-Service

### Highlights
- **Remediation hints.** Every analysis finding now shows a one-line hint under its message — what to create, fix or restart — on the Analysis page and in the Service view. Hints are static per finding code and translated with the UI; the finding JSON is unchanged.
- **Service picker in the request console.** Pick a namespace and a Service (and a port when it has several) and the URL becomes `http://<name>.<ns>.svc.cluster.local:<port>/`, keeping any path you typed. Typing a URL by hand still works.
- **Create a VirtualService or DestinationRule from the Service page.** Admins and editors get two buttons that open the editor with the template already pointed at the Service: namespace, name and host filled in, Form tab ready.

### Upgrade notes
- No breaking changes; existing sessions stay valid. The chart is unchanged apart from the version.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.6.0 -n <namespace> --reset-then-reuse-values`

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.6.0 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v1.6.0/install.yaml
```
Image `ghcr.io/wonjune95/sealane:1.6.0` (linux/amd64, linux/arm64) and the chart are signed with cosign (keyless); the SBOM is attached below.
