# Sealane v1.9.0

## Server errors in your language

### Highlights
- **Coded server errors.** Sealane's own error messages — sign-in failures and throttling, account and cluster validation, "you cannot change your own role", the viewer read-only refusal, the edit conflict — now carry a stable `code` in the error envelope (`error.code`, additive; `message` is unchanged). The UI shows the message in the active language, so a Korean user no longer sees English in toasts and the login form. Kubernetes validation and admission messages are passed through as before.
- **Clearer Korean** for the viewer refusal, the login failure and the request console host prompt.

### Upgrade notes
- No breaking changes; existing sessions stay valid. The chart is unchanged apart from the version. API clients may read `error.code`; older clients ignore it.
- `helm upgrade sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.9.0 -n <namespace> --reset-then-reuse-values`

### Install
```sh
helm install sealane oci://ghcr.io/wonjune95/charts/sealane --version 1.9.0 -n sealane --create-namespace
# or
kubectl apply -f https://github.com/wonjune95/sealane/releases/download/v1.9.0/install.yaml
```
Image `ghcr.io/wonjune95/sealane:1.9.0` (linux/amd64, linux/arm64) and the chart are signed with cosign (keyless); the SBOM is attached below.
