# Sealane v1.9.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v1.9.0: Sealane's own server error messages carry a stable `code`, and the UI shows them in the active language; Kubernetes/validation passthrough messages stay as they are.

**Architecture:** The error envelope gains an optional `code` (slug). Only fixed, Sealane-authored messages get one (the `writeError` calls with a literal message, plus the Conflict mapping and the login/throttle messages); `err.Error()` passthroughs do not. The web client keeps `message` and adds `code`; one helper `errorText(err)` returns `t('err.<code>')` when the locale has it, else the message. No new dependencies.

**Tech Stack:** Go 1.26, React 18, existing i18n (`t`, `Key`, `hack/check-i18n.sh`).

**Spec:** ROADMAP "Error codes for server messages, so the UI can translate them" (After 1.0 candidates); maintainer 2026-10-16: do it. The 1.x API promise (`docs/versioning.md`) allows additive fields.

## Global Constraints
- Korean only in `web/src/i18n/ko.json`, `README.ko.md`, `docs/superpowers/`, `docs/announcement.ko.md`; every new UI string in both locales; `hack/check-i18n.sh`.
- Go scoped `./cmd/... ./internal/...`; `gofmt`, `go vet`, `go test` (+ `-race ./internal/api/`). Frontend `cd web && npm run build && npm run lint && ../hack/check-i18n.sh`; `npm run test:ui` against the dev server.
- No new dependencies; no commit trailers; backend messages stay English; smallest working code. `hack/e2e.sh` greps some messages — keep `message` unchanged.

## Tasks

### Task 1: `code` on Sealane-authored errors (Go)
**Files:** `internal/api/errors.go`, every `writeError` call with a literal message (`internal/api/account.go`, `clusters.go`, `login.go`, `oidc.go`, `requesttest.go`, `routematch.go`, `server.go`), `internal/api/*_test.go` where envelopes are asserted, `docs/api.md` (or wherever the error envelope is documented — `git grep -n httpStatus docs`).
- `errBody` gains `Code string \`json:"code,omitempty"\``. Add `func writeCoded(w, status int, reason, code, msg string)`; `writeError` stays for passthroughs (`err.Error()` messages, which are Kubernetes or validation text and are not translated).
- Codes (slug, lower-kebab): `password-incorrect`, `accounts-not-configured`, `dev-mode-no-accounts`, `admin-required`, `username-invalid`, `invalid-body`, `role-invalid`, `own-role`, `password-too-short`, `password-required`, `admin-undeletable`, `own-account`, `sso-no-password`, `clusters-not-configured`, `local-cluster-readonly`, `cluster-name-invalid`, `kubeconfig-empty`, `conflict` (the `writeK8sError` Conflict branch), `dev-mode-no-login`, `too-many-attempts`, `invalid-credentials` (login.go: when the auth error is the "invalid username or password" case — check `internal/auth` for the sentinel; if there is no sentinel, add `var ErrInvalidCredentials` there and use `errors.Is`), `sso-not-configured`, `tester-disabled` (requesttest.go:93), `tester-admin-only`, `host-required`, `viewer-readonly` (server.go:137). Messages stay exactly as they are.
- Tests: extend an existing handler test (e.g. the login throttle test and one account test) to assert `code`; `go test ./internal/api/`.
- Commit: `API: a stable code on Sealane-authored error messages`.

### Task 2: the UI translates coded errors (web)
**Files:** `web/src/api/client.ts`, `web/src/i18n/en.json`, `ko.json`, every site that renders `err.message` (`git grep -n "instanceof ApiError" web/src`), `web/src/pages/Login.tsx` if it maps status codes by hand, `web/tests/` (one assertion in an existing test, e.g. `services.mjs` or `editor-focus.mjs`, with a mocked 409 `{error:{reason:'Conflict',code:'conflict',message:'…'}}` → the Korean/English text from the locale).
- `ApiError` gains `code?: string`; `request()` reads `env.error.code`.
- `export function errorText(err: unknown): string` in `client.ts`: `err instanceof ApiError && err.code && \`err.${err.code}\` in messages ? t(\`err.${err.code}\` as Key) : err instanceof Error ? err.message : String(err)` — check how `t`/the locale table is exposed in `web/src/i18n/index.ts` and use what is there (a `has(key)` if one exists; otherwise compare `t(key) !== key`).
- `err.<code>` keys in both locales for every code in Task 1, English identical to the server message, Korean translated.
- Replace the `err instanceof ApiError ? err.message : String(err)` sites with `errorText(err)`.
- Commit: `UI: show coded server errors in the active language`.
